### 5.26 晚间直播｜Product Manager of Cobo Agentic Wallet (20 pts) ✅ 已提交
参加了 Cobo Agentic Wallet 产品经理的分享直播。

关键收获：Cobo 的 Agentic Wallet 核心设计思路是「可编程权限 + 链上策略执行」——不是让 Agent 完全控制钱包，而是通过 pre-defined policies（预算上限、合约白名单、时间窗口）限制 Agent 能做什么。这解决了 Agent 支付场景里的核心矛盾：既要自动化执行，又要防止 Agent 跑路。对我们在做 Agent Payment Commerce 赛道的人来说，理解这些底层限制机制比看产品 UI 更重要。
