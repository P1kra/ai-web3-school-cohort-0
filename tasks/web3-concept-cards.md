# Web3 基础概念卡片

## 1. 密码学基础
- **是什么：** 哈希、公私钥、数字签名——Web3 安全的数学地基。
- **为什么重要：** 没有密码学就没有"你的资产只有你能动"。
- **关键点：** 私钥=所有权，公钥=地址，签名=证明"这操作是我同意的"。

## 2. 钱包
- **是什么：** 不只是存币工具，而是身份入口+签名器。
- **为什么重要：** 不管理你的私钥，任何链上操作都做不了。
- **关键点：** EOA（普通地址）→ 一个人一把钥匙；智能账户 → 可以多人、设规则、设限额。后者更适合 Agent。

## 3. 智能合约
- **是什么：** 跑在链上的代码，不可篡改，自动执行规则。
- **为什么重要：** Web3 的"规则引擎"——DeFi、NFT、DAO 全部跑在合约上。
- **关键点：** 跟传统代码的区别：一旦部署就不能偷偷改，所有人都能查——AI 调合约必须理解这个边界。

## 4. 网络与共识
- **是什么：** 区块链怎么让所有人对同一份账本达成一致。
- **为什么重要：** 去中心化的底层保障——不能有人说了算。
- **关键点：** L1 做安全结算，L2 做速度和便宜。Agent 选链要考虑 Gas 和确认时间。

## 5. 账户抽象（AA）
- **是什么：** 把钱包从"一把钥匙一个人"升级成"可编程账户"。
- **为什么重要：** 这是 Agent 用钱包的前提——设置额度、时间锁、多签、自动执行。
- **关键点：** 传统钱包要么全部权限、要么没有。AA 可以"每天最多花 0.1 ETH，只有这个 Agent 能用"。
