# AI 基础概念卡片

> 使用 Hermes Agent (DeepSeek V4 Pro) 辅助生成草稿，人工逐条复核、改写、补充案例。
> 最终版由皮卡确认后定稿。

## 1. LLM（大语言模型）
- **是什么：** 用海量文本训练出来的 AI 模型，能理解语言、回答问题、写代码。
- **为什么重要：** 所有 AI Agent 的"大脑"，决定了能做什么、做得多好。
- **误区：** LLM 不是搜索引擎，它会自信地编造不存在的事实（幻觉）。
- **边界：** 训练数据有截止日期，不知道之后发生的事；需要连接外部工具和知识才能获取最新信息。

## 2. Prompt（提示词）
- **是什么：** 你发给 AI 的指令，告诉它你是谁、要什么、怎么回答。
- **为什么重要：** 同一句话换种说法，AI 输出可以天差地别。好的 prompt 是精确的，不是越长越好。
- **误区：** 很多人以为 prompt 越长越好，实际堆砌反而让模型抓不住重点。
- **案例：** 「请作为我的 Learning Agent」vs「帮我学 Web3」——前者给了角色和边界，效果完全不同。

## 3. Context（上下文）
- **是什么：** AI 一次聊天窗口里能"看到"的全部信息——你的问题、之前的对话、加载的资料。
- **为什么重要：** 上下文决定了 AI 能参考多少信息来回答。超出窗口就"失忆"了。
- **误区：** 以为塞越多越好。如果把合约源码、审计报告、讨论记录全扔进去，模型可能只看前三行。
- **边界：** 不可信来源（随机网页）和可信来源（系统规则）应该分开标注，不能混在一起。

## 4. Agent（智能体）
- **是什么：** 不只是回答问题，而是能主动规划、调用工具、执行多步任务的 AI。
- **为什么重要：** 这是从"AI 帮你回答"到"AI 帮你做事"的跨越。
- **误区：** Agent 不是"自主 AI"，它只是在受限循环里执行——必须有人设权限、设边界、设停止条件。
- **案例：** Hermes Agent 能读文件、跑代码、查 API、提交任务——但每一步写入操作都需要人工确认。

## 5. MCP（模型上下文协议）
- **是什么：** 一套标准协议，让 AI 能统一接入各种外部工具和数据源。
- **为什么重要：** 没有 MCP，每个 AI 要单独适配每个工具。有了 MCP，接入一次到处能用。
- **类比：** USB-C——不管什么设备，插上就能用。MCP 就是 AI 和工具之间的 USB-C。
- **边界：** MCP 定义的是"怎么连"，不管"该不该连"。权限控制仍然需要单独设计。

## 6. RAG（检索增强生成）
- **是什么：** 让 AI 在回答前先从外部知识库检索相关资料，再结合检索结果生成回答。
- **为什么重要：** 解决了 LLM 知识过期和幻觉问题——先查再答，有据可依。
- **误区：** RAG 不是"接了就能用"。检索质量决定答案质量，垃圾文档进去垃圾回答出来。
- **案例：** 给 Agent 接上 Handbook 文档库，问"账户抽象是什么"→ 先检索 Handbook 相关内容 → 基于原文回答，而不是凭空编。
