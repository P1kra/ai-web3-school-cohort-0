🤖 AI × Web3 Agent 钱包模拟器

交互式学习工件 — 理解 AI Agent 与 Web3 钱包协作的边界与确认点

1️⃣ 用户输入 2️⃣ Agent 分析 3️⃣ 生成交易 4️⃣ 人工确认 5️⃣ 链上执行 6️⃣ 验证结果

🔗 当前工作流

用户请求→ Agent 解析→ 构建交易→ ⚠️ 人工确认→ 钱包签名→ 链上执行→ 验证结果

📖 这个工件教你什么

  • Agent 能做什么：解析意图、查询链上数据、构造交易参数、验证结果
  • Agent 不能做什么：自动签名、自动授权转账、绕过人工确认操作资金
  • 人工确认点（Human-in-the-loop）：每次涉及资金变动、合约写入、授权时，必须由人类确认并签名
  • 风险边界：Agent 是"建议者"而非"执行者"，钱包签名权始终在人类手中
