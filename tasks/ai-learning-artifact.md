# 交互式 AI 学习工件 — AI × Web3 Agent 钱包模拟器

## 工件概述

一个单文件 HTML 交互页面，模拟 AI Agent 在 Web3 场景中如何协助用户完成链上操作，同时清晰展示 **哪些步骤 Agent 能做、哪些必须人工确认**。

**在线体验：** [ai-web3-agent-wallet-simulator.html](https://github.com/P1kra/ai-web3-school-cohort-0/blob/master/tasks/ai-web3-agent-wallet-simulator.html)（下载后浏览器打开即可）

## 它教什么概念

核心概念：**受限 Agent (Restricted Agent) + Human-in-the-Loop**

AI Agent 在 Web3 场景中的角色边界：
- ✅ Agent **能**：解析用户意图、查询链上数据、构建交易参数、验证执行结果
- ❌ Agent **不能**：自动签名、自动授权转账、绕过人工确认操作资金
- ⚠️ **每次涉及资金变动都必须人工签名确认**

## 功能演示

### 预设场景（3种）
1. **买 NFT**：查询地板价 → 检查余额 → 构建交易 → 人工确认
2. **发代币**：验证地址 → 查余额 → 构建转账 → 人工确认
3. **DEX 兑换**：查最优路径 → 滑点保护 → 构建兑换 → 人工确认+授权

### 自定义场景
用户可以输入任意 Web3 操作请求，Agent 会解析意图并标注人工确认点。

### 交互流程（6步可视化）
```
用户输入 → Agent 分析 → 生成交易 → ⚠️ 人工确认 → 链上执行 → 验证结果
```

每一步有可视化步骤指示器和颜色区分：
- 🔵 蓝色 = AI 处理步骤
- 🟡 黄色 = 人工确认步骤
- 🟢 绿色 = 链上执行步骤

## 输入/输出示例

**输入：** "帮我在 OpenSea 上买一个 BAYC NFT，预算 0.5 ETH"

**Agent 输出：**
> 收到！购买 NFT 涉及：
> ① 查询 BAYC 地板价
> ② 检查钱包余额
> ③ 构建 purchase 交易
> ④ **需要你人工确认+签名**
> ⑤ 提交上链

**人工确认点：**
> ⚠️ 即将发送 0.5 ETH 购买 NFT。合约地址: 0xBC4C...aB12。Gas 预估: ~0.003 ETH。请确认是否签名？
> [确认 & 签名]  [拒绝]

## AI 辅助说明

| 部分 | AI 做了什么 | 人工做了什么 |
|------|-----------|------------|
| HTML/CSS 结构 | AI 生成 | 人工审阅调整 |
| JavaScript 交互逻辑 | AI 生成 | 人工验证确认点是否正确 |
| 场景设计 | AI 建议 NFT/转账/兑换 | 根据 Agent 钱包方向确定 | 
| 视觉设计 | AI 生成深色主题 | 确认配色和可读性 |
| 概念准确性 | AI 解释 Restricted Agent | 对照 Handbook 确认 |
